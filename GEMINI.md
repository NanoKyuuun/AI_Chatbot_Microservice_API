# AI Chatbot Microservice API - Project Instructions

## GitHub Workflow & Issue Management
- **Code Updates:** Every time code is updated or a task is completed, changes must be pushed to the GitHub repository.
- **Assigning & Closing Issues:** 
    1. Assign the issue to the currently logged-in user (`gh issue edit <issue_id> --add-assignee "@me"`).
    2. Close the issue using the GitHub CLI (`gh issue close <issue_id>`).
- **Commit Messages:** Use clear and descriptive commit messages that reference the issue ID (e.g., "feat: setup project structure (fixes #1)").
